Розробити невеликий VCL-застосунок «Журнал подій».

## 1. Модель даних

Подія повинна містити:

- ID;
- дату та час;
- текст;
- рівень важливості: Info, Warning, Error.

## 2. Інтерфейс

- Реалізувати головне вікно з табличним відображенням подій.
- Для кожного запису мають відображатися всі вищевказані атрибути.

## 3. Функціональні вимоги

- Імпорт даних

  Забезпечити завантаження історії подій із файлу формату JSON. Застосунок має бути стійким до
  некоректного формату або невалідних даних.

- Пошук та фільтрація:
  - Пошук записів за текстом подій
  - Фільтрація за рівнем важливості

- Фонова генерація (симуляція): Надати можливість увімкнення генератора подій. Після активації
  програма повинна автоматично створювати та додавати до загального списку одну випадкову подію
  щосекунди. Цей процес має виконуватися у фоновому потоці не блокуючи інтерфейс.
